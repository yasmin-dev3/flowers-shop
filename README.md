# 🌸 Flowers Shop

## Description

Flowers Shop est une boutique de fleurs en ligne développée avec HTML, CSS et JavaScript.

Le site permet aux utilisateurs de :
- Découvrir différentes fleurs
- Consulter les produits
- Ajouter des articles au panier
- Naviguer facilement grâce à une interface moderne et responsive

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Aperçu

Le projet est responsive et compatible avec les appareils mobiles.
